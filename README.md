# Telco Churn Analysis
## Overview

Utilizing a ![step-by-step guide by Data Demystified](https://zyabkina.com/churn-analysis-in-excel-telecom-example/), this repository analyzes the types of churn analysis done in Excel.

## Architecture

This project utilizes the ![Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) dataset from BLASTCHAR on Kraggle.

The raw data contains 7043 rows (customers) and 21 columns (features) and is useful for predicting behavior to retain customers. Relevant customer data and demographics can be utilized for focused customer retention programs.

## Technology Stack

**Microsoft Excel:** PivotTables, PivotCharts, VLOOKUP
